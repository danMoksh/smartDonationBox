# Security Policy

## Supported Versions

Security patches and updates are provided for the latest firmware builds on the default branch.

| Version | Supported          |
| :------ | :----------------- |
| Latest  | Yes |
| < 1.0   | No                |

## Reporting a Vulnerability

If you discover a vulnerability or safety-critical defect in the embedded logic, motor actuation sequences, or telemetry reporting:

1. **Do not post vulnerabilities publicly on GitHub issues**.
2. Report the vulnerability privately via **[GitHub Security Advisories](https://github.com/danMoksh/smartDonationBox/security/advisories/new)** or email **mokshdandotiya@gmail.com** / **mishraneeraj@mitsgwalior.in**.
3. Include relevant pin configurations, firmware logs, and reproduction steps.

## Response SLA

- **Acknowledgement**: Within 48 hours
- **Triage**: Within 5 business days
